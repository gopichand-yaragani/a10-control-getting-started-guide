# Access and Login

After you install the A10 Control platform, follow the steps to sign in and access the application interface:

1. Sign in with the default credentials.
2. Reset the Password. For more details on the password requirements, refer to the [Manage Passwords](https://documentation.a10networks.com/SYM/Platform/Latest/html/Default.htm#Product/password_mgmt_rbac.htm%3FTocPath%3DOrganization%2520Admin%7CManage%2520Organization%7C_____8).
3. Sign in with the updated credentials. A10 Control application interface appears.
4.  On the A10 Control dashboard, user can configure the devices, certificates, and basic system settings to complete the initial setup.

# Access and Login

After you install and set up the A10 Control platform, follow these steps to sign in and begin using the platform:

1. Sign in with the default credentials.
2. Reset the Password. For more details on the Password requirements, refer to the [Manage Passwords](https://documentation.a10networks.com/SYM/Platform/Latest/html/Default.htm#Product/password_mgmt_rbac.htm%3FTocPath%3DOrganization%2520Admin%7CManage%2520Organization%7C_____8).
3.  On the A10 Control dashboard, complete the initial setup by configuring devices, certificates, and basic system settings.

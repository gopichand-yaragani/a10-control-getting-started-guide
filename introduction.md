# Introduction

Welcome to the A10 Control platform.

This getting started guide aids the network administrators with clear steps to deploy, access, and monitor the A10 Control platform with built-in dashboards and alerts.

### About A10 Control

The A10 Control platform helps network administrators easily monitor, configure, manage, and secure A10 devices from a single user-friendly dashboard.

### Intended Audience

**First-time A10 Control users** \
Understand the basics of A10 Control platform and initial setup.

**Network Administrators** \
Learn the fundamentals of A10 Control and follow simple steps to deploy and configure your A10 Control environment.

**Learners** \
Explore the product features to obtain familiarity with the A10 Control platform capabilities.

### Key Capabilities of A10 Control

* **Security and Access Control**\
  Multi-Factor Authentication (MFA) ensures secure login to the applications. Role-based access control provides granular permissions for managing users and roles.
* **Account Setup and Management**\
  Application teams create organization accounts. IT teams manage the internal and external users. Organization administrators handle platform updates and maintenance independently.
* **Secure Communication**\
  A10 Control and server instances securely communicate data through encrypted channels such as SSL/TLS.
* **Layered Security**\
  Network-level access controls and encryption protect data across subsystems.

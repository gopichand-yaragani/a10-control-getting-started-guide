# Introduction

**Welcome to the A10 Control platform.**

This getting started guide helps the network administrators with clear steps to deploy, access, and monitor the A10 Control platform with built-in dashboards and alerts.

### About A10 Control

The A10 Control platform helps network administrators easily monitor, configure, manage, and secure A10 devices from a single, user-friendly dashboard.

### Intended Audience

**First-time A10 Control users** – Understand the basics of A10 Control platform and initial setup. **Network Administrators** – Learn the fundamentals of A10 Control and follow simple steps to deploy and configure your first environment. \
**Learners** – Explore product dashboards, monitoring, alerts, and features to obtain familiarity with A10 Control platform core capabilities.

### Key Capabilities of A10 Control

* **Security and Access Control**: Multi-Factor Authentication (MFA) ensures secure login. Role-based access control provides granular permissions. Organization–Org Unit structure supports multiple admins managing users and roles.
* **Account Setup and Management**- Application teams can create organization accounts. IT teams manage the internal and external users. Organization admins handle platform updates and maintenance independently.
* **Secure Communication**- Only control messages, metrics, and telemetry data are exchanged between A10 Control and service instances. SSL encryption secures both internal and external communications.
* **Layered Security**- Network-level access controls and encryption protect data across subsystems. Isolated environments enhance overall security.
